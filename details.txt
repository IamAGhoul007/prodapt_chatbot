# Telecom AI Operations Center - Comprehensive Project Details

## 1. Project Overview & Architecture
The Telecom AI Operations Center is a multi-agent, multi-framework AI application designed to handle complex telecom operations, ranging from network diagnostics and billing resolution to policy inquiries and network analytics. 

**Frameworks Used:**
- **LangGraph**: Serves as the core orchestrator, managing state and routing between different specialized agents.
- **Google ADK (Agentic Development Kit)**: Used to build distinct microservices for Network Diagnostics and Billing Resolution. These run as remote Agent-to-Agent (A2A) services.
- **LlamaIndex**: Powers the Retrieval-Augmented Generation (RAG) for policy FAQs and Semantic SQL querying for analytics.
- **CrewAI**: Used for final customer communication, employing a multi-agent crew (Writer + Reviewer) to draft and polish the final response.
- **Streamlit**: Provides the interactive frontend User Interface.

## 2. Vivid Details of Features and Exact Data Flow

### The Data Flow Journey (Step-by-Step)
1. **User Input (Streamlit UI)**: The user enters a prompt (e.g., "Customer CUST-10002 was charged twice") into the Streamlit app (`ui/app.py`).
2. **State Initialization**: The UI creates an initial `AgentState` dictionary containing the `user_query`, an empty `agent_context`, an empty `execution_trace`, and an empty list of `messages`.
3. **LangGraph Orchestration (`orchestration/graph.py`)**: The state is passed to the compiled LangGraph workflow.
    - **Step A - Security Gate**: The graph always starts at the `security_gate_node`. It checks the query for blocked prompt-injection patterns (e.g., "ignore previous instructions", "bypass security"). If a violation is detected, it blocks execution and returns a security failure.
    - **Step B - Supervisor Routing**: If it passes security, it moves to the `supervisor_node`. The supervisor (powered by Gemini) reviews the current `agent_context` and the `user_query` to decide which specialist agent to consult next. It chooses from predefined routes: `policy_rag`, `network_analytics`, `network_diagnostics_adk`, `billing_resolution_adk`, or `customer_comms_crew`.
    - **Step C - Specialist Execution**: Based on the supervisor's decision, the flow moves to the specific node. The chosen node performs its task, appends its result to `agent_context`, logs its execution in `execution_trace`, and then routes *back* to the supervisor.
    - **Step D - Loop or Finish**: The supervisor evaluates the new context. If it needs more information, it routes to another specialist. If it has sufficient information to answer the user, it routes to `customer_comms_crew`.
4. **Final Formatting (`customer_comms_crew_node`)**: 
    - A security check ensures no cross-contamination (e.g., multiple different customer IDs in context).
    - It invokes CrewAI (`orchestration/crew_nodes.py`), which uses a `writer` agent to draft an email based on the context, and a `reviewer` agent to polish it.
    - Personal Identifiable Information (PII) like the customer ID is masked (e.g., CUST-****).
    - The final string is saved to `final_response` in the state.
5. **Return to User**: LangGraph reaches `FINISH`. The Streamlit UI reads `final_response` and displays it, along with an expandable section showing the exact `execution_trace` of which agents ran and what they outputted.

### Deep Dive into Features & Microservices

1. **Network Diagnostics ADK (`adk-services/network_diagnostics/agent.py`)**
   - **How it works**: Runs as a separate Uvicorn server on port 8001. It is defined as a Google ADK Agent.
   - **Tools available**: `check_tower_status`, `run_connectivity_diagnostics`, `get_regional_network_summary`, `get_customer_contact`.
   - **Data Source**: Queries `telecom_ops.db` (SQLite) directly using SQL.

2. **Billing Resolution ADK (`adk-services/billing_resolution/agent.py`)**
   - **How it works**: Runs as a Uvicorn server on port 8002.
   - **Tools available**: `lookup_billing_account`, `check_duplicate_charges`, `apply_billing_credit`. It handles logic like checking if credits > $50 require manual approval.
   - **Data Source**: Queries `telecom_ops.db`.

3. **Policy RAG (`llamaindex_rag/document_rag.py`)**
   - **How it works**: Uses LlamaIndex to ingest documents from `data/documents` and stores embeddings in `data/vector_index` using HuggingFace embeddings (`all-MiniLM-L6-v2`) and Gemini as the LLM. 
   - **Usage**: Answers unstructured questions about roaming, SLAs, etc.

4. **Network Analytics SQL Semantic Search (`llamaindex_rag/sql_semantic_search.py`)**
   - **How it works**: Uses LlamaIndex's `SQLTableRetrieverQueryEngine`. It has an explicit schema context mapping for tables (`network_towers`, `network_outages`, `tower_performance`, `open_incidents`). It translates natural language to SQL queries and executes them to find analytics (e.g., "Which region has the most outages?").
   - **Security**: Hardcodes block words (like "billing", "cust-") to ensure it doesn't accidentally query billing data, enforcing separation of concerns.

5. **Customer Communications Crew (`orchestration/crew_nodes.py`)**
   - **How it works**: A CrewAI Process with two agents (Communications Specialist and Quality Reviewer). It takes the aggregated, raw `agent_context` and transforms it into a polite, customer-ready response.

## 3. Sample Questions for Evaluation/Defense

If you are asked to defend or explain this project, here are sample questions and how you can answer them:

**Q1: How do you handle routing between different AI capabilities?**
*A1:* I use LangGraph with a Supervisor node. The supervisor acts as a router. It evaluates the user's query and the current state (context gathered so far) and decides which subsystem to call next—whether it's the Billing ADK, Network ADK, LlamaIndex RAG, or CrewAI for final formatting.

**Q2: Why did you separate Network and Billing into distinct ADK services?**
*A2:* For microservice architecture and security. By having them on separate ports (8001 and 8002) as ADK A2A (Agent-to-Agent) services, they can be scaled independently, and their tool permissions are isolated. Billing cannot access Network tools, and vice versa.

**Q3: How do you prevent prompt injection or security breaches?**
*A3:* I implemented multiple layers. First, a `security_gate_node` in LangGraph that checks for keywords like "bypass security". Second, inside the SQL Analytics module, I block billing-related keywords. Third, in the final CrewAI node, I run a regex to ensure data from only one Customer ID is present, preventing cross-tenant data leaks, and I mask the IDs before outputting.

**Q4: How does LlamaIndex handle SQL in your project?**
*A4:* I used `SQLTableRetrieverQueryEngine` from LlamaIndex. I explicitly defined the context and schema for specific network tables. When a user asks an analytics question, the LLM converts the natural language into an SQL query, executes it against `telecom_ops.db`, and summarizes the result.

**Q5: How does the data flow from the ADK services back to the user?**
*A5:* The Supervisor calls a remote client function (`orchestration/adk_remote_client.py`), which creates an HTTP session with the ADK server (e.g. port 8001). The ADK runs its tools, returns a text response, which is appended to `agent_context` in the LangGraph state. Eventually, the Supervisor routes to CrewAI, which formats that raw context into a friendly email, which is then sent to the Streamlit UI.

```python
import subprocess
import time
import sys
import os
import httpx

os.environ["PYTHONIOENCODING"] = "utf-8"

def wait_for_service(url: str, name: str, timeout: int = 30):
    print(f"  Waiting for {name} at {url}...")
    deadline = time.time() + timeout
    while time.time() < deadline:
        try:
            r = httpx.get(url + "/.well-known/agent-card.json", timeout=2.0)
            if r.status_code < 500:
                print(f"  [OK] {name} is up!")
                return True
        except Exception:
            pass
        time.sleep(1)
    print(f"  [WARN] {name} did NOT respond within {timeout}s -- continuing anyway.")
    return False

def start_services():
    print("=" * 50)
    print("Starting Network ADK Service on port 8001...")
    network_process = subprocess.Popen(
        [sys.executable, "adk-services/network_diagnostics/agent.py"],
        cwd=os.path.dirname(os.path.abspath(__file__))
    )

    print("Starting Billing ADK Service on port 8002...")
    billing_process = subprocess.Popen(
        [sys.executable, "adk-services/billing_resolution/agent.py"],
        cwd=os.path.dirname(os.path.abspath(__file__))
    )

    wait_for_service("http://localhost:8001", "Network Diagnostics ADK")
    wait_for_service("http://localhost:8002", "Billing Resolution ADK")

    print("Starting Streamlit UI on port 8501...")
    streamlit_process = subprocess.Popen(
        [sys.executable, "-m", "streamlit", "run", "ui/app.py"],
        cwd=os.path.dirname(os.path.abspath(__file__))
    )

    print("=" * 50)
    print("All services started!")
    try:
        network_process.wait()
        billing_process.wait()
        streamlit_process.wait()
    except KeyboardInterrupt:
        print("\nShutting down all services...")
        network_process.terminate()
        billing_process.terminate()
        streamlit_process.terminate()

if __name__ == "__main__":
    start_services()
```

### 4. `orchestration/crew_nodes.py`
```python
from crewai import Agent, Task, Crew, Process
import os

os.environ["GEMINI_API_KEY"] = os.environ.get("GOOGLE_API_KEY", "")
llm_model = "gemini/gemini-2.5-flash"

def format_customer_response(user_query: str, agent_context: str) -> str:
    writer = Agent(role='Communications Specialist', goal='Draft clear responses.', backstory='...', llm=llm_model)
    reviewer = Agent(role='Quality Reviewer', goal='Review response.', backstory='...', llm=llm_model)
    
    draft_task = Task(description=f"Query: '{user_query}'. Context: {agent_context}. Draft email.", expected_output="Draft.", agent=writer)
    review_task = Task(description="Review draft.", expected_output="Final email.", agent=reviewer)
    
    crew = Crew(agents=[writer, reviewer], tasks=[draft_task, review_task], process=Process.sequential)
    return str(crew.kickoff())
```
